# Default instructor portrait

`default-portrait.svg` is an original, decorative vector illustration made for
TamkeeNova: a neutral, faceless pearl/glass bust in the platform's teal palette.
It does not depict a real person or imply an instructor's gender or identity.
There are no external images, fonts, scripts, remote URLs or third-party assets.

The shared `TrainerPortraitDirective` uses it when an API image is absent/blank
or fails to load. Real uploaded images always take priority. The directory's
four decorative hero slots can also use this asset without adding instructors
to the catalog, statistics or database. It is served locally and needs no
external image service or database change.
