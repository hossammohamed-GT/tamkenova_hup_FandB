# Noto Kufi Arabic — platform Arabic UI font

The requested family was confirmed by the user from the reference site's
Computed / Rendered Fonts panel: **Noto Kufi Arabic**. We ship licensed font
files, not copied styles or assets from the reference site.

- Source: https://github.com/google/fonts/tree/main/ofl/notokufiarabic
- Distribution: `@fontsource-variable/noto-kufi-arabic@5.3.0`, Google Fonts v27
- Download: https://registry.npmjs.org/@fontsource-variable/noto-kufi-arabic/-/noto-kufi-arabic-5.3.0.tgz
- Copyright 2019–2022 Google LLC. All Rights Reserved.
- License: SIL Open Font License 1.1; the complete notice is in `OFL.txt`.
- Unmodified WOFF2 files; normal variable weight axis 100–900. Arabic, Latin
  and Latin Extended subsets keep mixed-language text consistent.

`src/styles.css` declares unicode-ranged, self-hosted `@font-face` rules with
`font-display: swap`. No external font request is required for Arabic text.
The Arabic subset is preloaded from `src/index.html`; versioned URLs prevent
old font assets being mistaken for future versions. Include `public/fonts`
when deploying, as with the other Angular public assets.

Arabic locale overrides shared sans/display tokens, covering public pages,
headings, navigation, forms, dialogs, and all portal roles without a universal
font override that would destroy Font Awesome icons. English retains the
existing IBM Plex Sans stack with Noto Kufi Arabic as the Arabic-glyph fallback;
monospace numeric/code typography keeps its existing Latin face. Certificate
artwork and logo images are separate designed assets, not UI text, and are not
regenerated by this typography change.
